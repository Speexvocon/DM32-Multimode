# Installable applets

These DAPP v1 packages are compiled from the adjacent open script sources.
Counter uses display/serial/key services; SAME Watch uses the native weather
decoder. Neither package has a script transmit instruction. The separate
native PCM tool has its own explicit RX/TX sessions.

Compile, inspect and install with [the applet guide](../docs/APPLETS.md).
Installing a package does not run it and does not replace firmware. Hashes and
source identity are in [manifest.json](manifest.json).
